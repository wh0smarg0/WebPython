# 🏛️ Система обліку платників податків (Варіант 12) — ЛБ №3

Вебзастосунок на базі **FastAPI**, модернізований у межах лабораторної роботи №3. Систему переведено на **NoSQL-архітектуру** з використанням **MongoDB** для гнучкого збереження документів та асинхронної обробки даних.

---

## 🌟 Основний функціонал (ЛБ №3)

* **Перехід на NoSQL (MongoDB)**: Використання документо-орієнтованої бази даних замість реляційних таблиць.
* **Асинхронний драйвер Motor**: Повністю асинхронна взаємодія з базою даних (`async/await`), що забезпечує високу продуктивність.
* **Денормалізація даних**: Відмова від ресурсомістких `JOIN` на користь вкладених даних у документах нарахувань для миттєвого читання.
* **Гнучка схема (Schema-less)**: Можливість зберігання документів різної структури в межах однієї колекції.
* **Робота з ObjectId**: Реалізація коректної обробки 24-символьних ідентифікаторів MongoDB в інтерфейсі та API.
* **Інтерактивний пошук**: Жива фільтрація та підсвічування збігів у декількох колекціях одночасно.

---

## 🛠 Стек технологій

* **Backend**: FastAPI (Asynchronous framework).
* **База даних**: **MongoDB Community Server 7.0**.
* **Драйвер БД**: **Motor** (асинхронний драйвер для MongoDB).
* **Frontend**: Jinja2 Templates, Bootstrap 5, Vanilla JavaScript.

---

## 📂 Структура проєкту

* `main.py` — асинхронна серверна логіка, маршрути та CRUD операції з MongoDB.
* `database.py` — налаштування підключення `AsyncIOMotorClient` та опис колекцій.
* `templates/index.html` — адаптивний шаблон з підтримкою скороченого відображення `ObjectId`.

---

## 🚀 Запуск проєкту локально

1. **Налаштуйте MongoDB:**
* Запустіть сервер MongoDB (за замовчуванням на порту `27017`).
* Використовуйте **MongoDB Compass** для візуалізації бази даних `taxes_nosql_db`.


2. **Встановіть залежності:**
```bash
pip install fastapi uvicorn motor dnspython jinja2 python-multipart
```


3. **Запустіть сервер:**
```bash
uvicorn main:app --reload
```


4. **Доступ до системи:**
* **Головна сторінка:** `http://127.0.0.1:8000/`
* **Режим адміністратора:** `http://127.0.0.1:8000/?role=admin`
