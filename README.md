# 🏛️ Система обліку платників податків (Варіант 12) — ЛБ №7

Даний проєкт є вебзастосунком для автоматизації обліку платників податків. Він побудований на фреймворку **Flask** із використанням **PostgreSQL**. 

Основна мета роботи — реалізація системи безпечної аутентифікації, розмежування прав доступу (RBAC) та створення прозорого механізму аудиту дій користувачів.


## Ключовий функціонал

### 🔐 Аутентифікація та Безпека
- **Реєстрація та Вхід**: Реалізовано за допомогою `Flask-Login`.
- **Хешування паролів**: Безпечне збереження облікових даних.
- **Рольова модель**: 
  - **Користувач (Платник)**: Може подавати декларації, бачити власні борги, сплачувати податки та завантажувати PDF-квитанції.
  - **Адміністратор**: Має повний доступ до реєстру платників, керує акаунтами користувачів та бачить журнал системних подій.

### 🛠 Адміністрування (Admin Panel)
- **Керування користувачами**: Перегляд, модерація та видалення облікових записів.
- **Audit Log (Журнал аудиту)**: Фіксація кожної дії в системі (хто, що і коли зробив) на окремій вкладці адмін-панелі.
- **Глобальний пошук**: Пошук платників за ПІБ або ІПН у режимі реального часу (JS).

### 📧 Сервіси та Автоматизація
- **Email-сповіщення**: Автоматичне надсилання листів на пошту користувача після успішної оплати (через SMTP Gmail).
- **Генерація документів**: Створення фіскальних квитанцій у форматі **PDF** з підтримкою кирилиці.
- **Експорт**: Генерація звітів у форматі **CSV**.

## Технологічний стек
- **Backend**: Python 3.x, Flask.
- **Database**: PostgreSQL.
- **ORM**: SQLAlchemy.
- **Migrations**: Flask-Migrate (Alembic).
- **Frontend**: Bootstrap 5, Jinja2, Bootstrap Icons.
- **PDF Generation**: xhtml2pdf, ReportLab.



## Структура проєкту (Application Factory & Blueprints)
Проєкт організовано за принципом **Flask Application Factory**, що забезпечує модульність та масштабованість:

```text
WebPython/
├── app/             # Blueprint для основної логіки
│   ├── __init__.py
│   ├── views.py        # Роути та бізнес-логіка
│   ├── static/             # CSS, JS, Шрифти
│   ├── templates/          # Jinja2 шаблони
│   ├── models.py           # Моделі бази даних (User, Taxpayer, AuditLog...)
│   ├── forms.py            # Валідація форм Flask-WTF
│   └── __init__.py         # Фабрика create_app()
├── migrations/             # Міграції бази даних
├── config.py               # Конфігураційний клас
├── run.py                  # Точка входу
└── requirements.txt        # Залежності

```

## Встановлення та запуск

### Клонуйте репозиторій + налаштуйте віртуальне середовище:

```bash
    python -m venv .venv
    .venv\Scripts\activate
    pip install -r requirements.txt
```

### Налаштуйте базу даних (PostgreSQL):

```bash
    flask db upgrade
```

### Налаштування середовища (Environment Variables):
* Створіть файл .env або пропишіть у config.py пароль додатка (App Password) для Gmail.

### Запуск:

```bash
    python run.py
```
