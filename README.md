# 🏛️ Система обліку платників податків (Варіант 12) — ЛБ №6

Вебзастосунок, перенесений з Django на мікрофреймворк **Flask** у межах лабораторної роботи №6. Основна мета — реалізація аналогічного функціоналу за допомогою **SQLAlchemy ORM** та демонстрація гнучкості мікрофреймворків.

---

## 🌟 Ключові особливості (ЛБ №6: Migration to Flask)

* **Flask & SQLAlchemy ORM**: Повний перехід від монолітної архітектури Django до модульного Flask. Робота з базою даних через SQLAlchemy (моделі, запити, зв’язки).
* **Flask-Migrate (Alembic)**: Управління схемою бази даних PostgreSQL за допомогою міграцій замість вбудованих засобів Django.
* **WTForms & Валідація**:
    * Реалізація форм через `Flask-WTF`.
    * Сувора валідація ІПН (точно 10 цифр) на рівні Python-класів.
    * Обробка помилок `IntegrityError` (NOT NULL, UNIQUE) на рівні бази даних.
* **Динамічний CRUD (Modal Windows)**: Повністю збережена логіка роботи через модальні вікна. Взаємодія здійснюється через Flask-маршрути (`routes`) та JavaScript.
* **Експорт у CSV (Excel Optimized)**: Вдосконалений функціонал експорту з використанням **BOM (Byte Order Mark)** та роздільника `;`, що забезпечує коректне відображення кирилиці в Microsoft Excel.
* **Генерація квитанцій**: Система створення підтверджувальних документів про оплату у форматі `.txt` (з підтримкою завантаження через браузер).
* **Flash Messages**: Використання системи контекстних повідомлень Flask для підтвердження дій користувача (успішне додавання, видалення, оплата).

---

## 🛠 Стек технологій

* **Backend**: Flask 3.x (Python).
* **ORM**: SQLAlchemy (об’єктно-реляційне відображення).
* **База даних**: PostgreSQL.
* **Міграції**: Flask-Migrate / Alembic.
* **Форми**: WTForms.
* **Frontend**: Jinja2 (шаблонізатор), Bootstrap 5, JavaScript (Vanilla).

---

## 📂 Структура проєкту (ЛБ №6)

* `app.py` — головний файл застосунку: ініціалізація Flask, конфігурація БД, опис моделей та всіх маршрутів (маршрутизація).
* `forms.py` — опис класів форм `TaxpayerForm` та `TaxRecordForm` з використанням валідаторів.
* `migrations/` — папка з генерованими скриптами зміни структури БД.
* `templates/` — Jinja2 шаблони:
    * `index.html` — головна сторінка з адаптивною логікою для Адміна та Користувача.
* `requirements.txt` — список усіх необхідних бібліотек для розгортання проєкту.

---

## 🚀 Запуск проєкту локально

1.  **Встановіть залежності:**
    ```bash
    pip install flask flask-sqlalchemy flask-migrate flask-wtf psycopg2-binary
    ```

2.  **Застосуйте міграції (створення таблиць у вашій PostgreSQL):**
    ```bash
    flask db upgrade
    ```

3.  **Запустіть сервер:**
    ```bash
    flask run --debug
    ```

## 📋 Основні сценарії використання:

1.  **Розрахунок податку**: При додаванні нового нарахування система автоматично обчислює суму на основі ставки податку (наприклад, 18% ПДФО) та введеного доходу.
2.  **Редагування через JS**: При натисканні на олівець у реєстрі, JavaScript динамічно змінює `action` форми та підставляє дані в модальне вікно без перезавантаження.
3.  **Оплата та Квитанція**: Після зміни статусу на «Сплачено», користувач отримує доступ до завантаження офіційної квитанції, що генерується сервером на льоту.
4.  **Звітність**: Адміністратор може в один клік отримати CSV-файл усього реєстру, який автоматично відкривається в Excel без помилок кодування.
