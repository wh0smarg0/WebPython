# 🏛️ Система обліку платників податків (Варіант 12)

Вебзастосунок на базі **FastAPI**, розроблений у межах лабораторної роботи №1. Система дозволяє вести електронний реєстр платників податків, керувати типами податків та автоматизувати процес фінансових нарахувань.

--- 

## 🌟 Основний функціонал
* **Реєстр платників**: Повний цикл CRUD (створення, читання, оновлення, видалення) для бази даних платників.
* **Рольова модель доступу**: 
  * `Користувач`: Тільки перегляд даних.
  * `Адміністратор`: Повний доступ до редагування, видалення та нарахування податків.
* **Журнал нарахувань**: Автоматичний розрахунок суми податку на основі обраної ставки та доходу платника.
* **Інтерактивний пошук**: Жива фільтрація обох таблиць одночасно з візуальним підсвічуванням збігів (ПІБ або ІПН).
* **OpenAPI Документація**: Налаштована специфікація Swagger (версія 1.2.0).

## 🛠 Стек технологій
* **Backend**: FastAPI, SQLAlchemy (ORM), Jinja2 (SSR).
* **База даних**: SQLite.
* **Frontend**: HTML5, CSS3 (Bootstrap 5), JavaScript (Vanilla).
* **Контроль версій**: Git (гілка `лаб1`).

## 📂 Структура проєкту
* `main.py` — серверна логіка та маршрути.
* `models.py` — описи таблиць БД (Платники, Типи податків, Нарахування).
* `database.py` — конфігурація підключення до SQLite.
* `templates/` — HTML-шаблони для рендерингу інтерфейсу.

---

## 🚀 Запуск проєкту локально

1. **Встановіть залежності:**
   ```bash
   pip install fastapi sqlalchemy uvicorn jinja2 python-multipart

2. **Запустіть сервер:**
    ```bash
    uvicorn main:app --reload

3. **Доступ до системи:**
   * **Головна сторінка:** `http://127.0.0.1:8000/`
   * **Режим адміністратора:** `http://127.0.0.1:8000/?role=admin`
   * **Документація API:** `http://127.0.0.1:8000/docs`
