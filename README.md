# 🏛️ Система обліку платників податків (Варіант 12) — ЛБ №4

Вебзастосунок на базі **Django Framework**, розроблений у межах лабораторної роботи №4. Проєкт демонструє перехід від мікрофреймворків до повноцінної **Enterprise-архітектури** з використанням реляційної СУБД **PostgreSQL** та вбудованої системи безпеки Django.

---

## 🌟 Ключові особливості (ЛБ №4)

* **Перехід на Django MTV**: Використання класичного патерну *Model-Template-View* для чіткого розділення бізнес-логіки, даних та інтерфейсу.
* **Реляційна СУБД PostgreSQL**: Повернення до суворої типізації та цілісності даних (ACID) через **Django ORM**.
* **Система RBAC (Role-Based Access Control)**: 
    * **Адміністратор (Інспектор)**: Повний доступ до реєстрів, керування типами податків та створення нарахувань.
    * **Користувач (Платник)**: Персоналізований "Особистий кабінет" із доступом лише до власних даних.
* **Механізм авторизації**: Реалізація безпечного входу через `django.contrib.auth` із захистом від перебору паролів та сесійною підтримкою.
* **Фінансова логіка**: Автоматичний розрахунок податкових сум на основі діючих ставок та ведення балансу ("Загальний борг").
* **Інтерактивна оплата**: Функціонал миттєвої зміни статусу нарахування (`is_paid`) з візуальним підтвердженням у реальному часі.

---

## 🛠 Стек технологій

* **Backend**: **Django 5.0+** (Python framework).
* **База даних**: **PostgreSQL** (через драйвер `psycopg2`).
* **ORM**: Django Object-Relational Mapper.
* **Frontend**: Django Template Language (DTL), Bootstrap 5, Bootstrap Icons.
* **Безпека**: CSRF protection, PBKDF2 password hashing.

---

## 📂 Структура проєкту

* `tax_service/` — ядро проєкту (налаштування БД, маршрутизація, параметри авторизації).
* `taxes/` — основний додаток:
    * `models.py` — реляційні моделі (`Taxpayer`, `TaxType`, `TaxRecord`).
    * `views.py` — логіка обробки запитів та фінансових розрахунків.
* `templates/` — адаптивні шаблони:
    * `login.html` — стилізована сторінка входу в кабінет.
    * `index.html` — дашборд із розділенням інтерфейсу за ролями.

## 🚀 Запуск проєкту локально

1.  **Налаштуйте PostgreSQL:**
    * Створіть базу даних `taxes_db`.
    * Налаштуйте доступ (user/password) у файлі `settings.py`.

2.  **Встановіть залежності:**
    ```bash
    pip install django psycopg2-binary
    ```

3.  **Виконайте міграції та створіть адміна:**
    ```bash
    python manage.py makemigrations
    python manage.py migrate
    python manage.py createsuperuser
    ```

4.  **Запустіть сервер:**
    ```bash
    python manage.py runserver
    ```

5.  **Доступ до системи:**
    * **Вхід:** `http://127.0.0.1:8000/login/`
    * **Адмін-панель Django:** `http://127.0.0.1:8000/admin/`

## 📋 Інструкція для перевірки
Для тестування кабінету користувача необхідно в адмін-панелі створити об'єкт `User`, створити об'єкт `Taxpayer` та пов'язати їх через поле **"Обліковий запис"**. Після цього при вході під даним користувачем система відобразить лише його персональну статистику.
