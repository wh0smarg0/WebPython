# 🏛️ Система обліку платників податків (Варіант 12) — ЛБ №2

Вебзастосунок на базі **FastAPI**, модернізований у межах лабораторної роботи №2. Систему переведено на клієнт-серверну архітектуру з використанням **PostgreSQL** для надійного збереження фінансових даних.

---

## 🌟 Основний функціонал (ЛБ №2)

* **Міграція на PostgreSQL**: Повна відмова від SQLite на користь промислової СКРБД.
* **Пряме керування через SQL**: Реалізація CRUD-операцій за допомогою низькорівневого драйвера **psycopg2** та курсорів.
* **Динамічний довідник податків**: Можливість додавати нові типи податків (ПДВ, ПДФО, Військовий збір) через інтерфейс.
* **Складні SQL-запити**: Використання `JOIN` для об'єднання даних з трьох таблиць у реальному часі.
* **Рольова модель**: Розділення прав між `Користувачем` (перегляд) та `Адміністратором` (редагування/нарахування).
* **Живий пошук**: Фільтрація записів з візуальним підсвічуванням збігів на боці клієнта.

## 🛠 Стек технологій

* **Backend**: FastAPI, Jinja2 (SSR).
* **База даних**: **PostgreSQL 16** (замість SQLite).
* **Драйвер БД**: **Psycopg2** (замість SQLAlchemy ORM).
* **Frontend**: Bootstrap 5, JavaScript (Vanilla).

## 📂 Структура проєкту

* `main.py` — серверна логіка, маршрути та виконання SQL-запитів.
* `database.py` — конфігурація підключення до сервера PostgreSQL та ініціалізація таблиць (DDL).
* `templates/index.html` — адаптивний шаблон інтерфейсу.

---

## 🚀 Запуск проєкту локально

1. **Налаштуйте PostgreSQL:**
* Створіть базу даних `taxes_db` у pgAdmin 4.
* Переконайтеся, що сервер запущений на порту `5432`.


2. **Встановіть залежності:**
```bash
pip install fastapi uvicorn psycopg2-binary jinja2 python-multipart
```


3. **Запустіть сервер:**
```bash
uvicorn main:app --reload
```


4. **Доступ до системи:**
* **Головна сторінка:** `http://127.0.0.1:8000/`
* **Режим адміністратора:** `http://127.0.0.1:8000/?role=admin`
