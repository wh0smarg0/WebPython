# 🏛️ Система обліку платників податків (Варіант 12) — ЛБ №5

Вебзастосунок на базі **Django Framework**, вдосконалений у межах лабораторної роботи №5. Основний фокус зміщено на **професійну обробку форм**, глибоку **валідацію даних** та розширення функціоналу **документообігу**.

---

## 🌟 Нові можливості (ЛБ №5)

* **Django ModelForms & Widgets**: Реалізація складних форм для сутностей `Taxpayer` та `TaxRecord` із кастомною стилізацією через Bootstrap-віджети безпосередньо у Python-коді.
* **Багаторівнева валідація**:
    * Перевірка формату ІПН (суворо 10 цифр).
    * Контроль унікальності платників у реєстрі.
    * Валідація фінансових полів (захист від від’ємного доходу).
* **Динамічний CRUD (Modal Windows)**: Редагування платників та нарахувань реалізовано через модальні вікна за допомогою **JavaScript (Fetch/DOM)**, що забезпечує роботу без повного перезавантаження сторінки.
* **Генерація PDF-документів**: Система автоматичного створення офіційних квитанцій про сплату податку з використанням бібліотеки `reportlab` (підтримка кирилиці/TrueType шрифтів).
* **Експорт даних (CSV)**: Функціонал для адміністратора, що дозволяє завантажити повний реєстр платників для зовнішньої звітності.
* **Вдосконалений UX**: Система повідомлень (`django.contrib.messages`) для інформування про успішні операції або помилки валідації.

---

## 🛠 Стек технологій

* **Backend**: Django 5.x / 6.x (Python).
* **База даних**: PostgreSQL (ACID compliance).
* **Генерація документів**: `reportlab` (PDF), `csv` module.
* **Frontend**: Bootstrap 5, Bootstrap Icons, JavaScript (Vanilla).
* **Валідація**: Django Clean Methods & Regex Validators.

---

## 📂 Структура проєкту (ЛБ №5)

* `taxes/` — основний додаток:
    * `models.py` — додано поле `paid_at` для фіксації часу транзакцій.
    * `forms.py` — **(Нове)** класи `ModelForm` із кастомною логікою валідації `clean_tin()`.
    * `views.py` — реалізовано логіку генерації PDF-потоків та обробку POST-запитів від форм.
* `templates/` — оновлені шаблони:
    * `index.html` — інтегровані модальні форми для редагування та блоки завантаження чеків.

---

## 🚀 Запуск проєкту локально

1.  **Встановіть залежності:**
    ```bash
    pip install django psycopg2-binary reportlab
    ```

2.  **Виконайте міграції (важливо для нових полів):**
    ```bash
    python manage.py makemigrations
    python manage.py migrate
    ```

3.  **Запустіть сервер:**
    ```bash
    python manage.py runserver
    ```

---

## 📋 Функції:

1.  **Валідація**:  додавання платника з ІПН, що містить літери або менше 10 цифр — система видасть помилку.
2.  **Редагування (Олівець)**: олівець у таблиці — відкриється модальне вікно, дані підтягнуться автоматично через JS.
3.  **Сплата та Чек**: після натискання «Сплатити» з'являється кнопка **«Квитанція PDF»**. Можливість завантажити її дає змогу перевірити коректність формування документа та відображення української мови.
4.  **Експорт**: кнопка «Експорт у CSV» у верхній частині панелі адміністратора для завантаження всього реєстру.
